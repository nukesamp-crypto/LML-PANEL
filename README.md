## 🛡️ حفاظت و خودکارسازی

> [!IMPORTANT]
> **Anti-Ban:** اسکنرها و بات‌های کاوشگر (zgrab، shodan، masscan، curl و …) قبل از رسیدن به دیتابیس شناسایی می‌شوند و در یک Tarpit کند گیر می‌افتند.

| قابلیت | توضیح |
|:---|:---|
| 🔑 **Rate-limit** | محدودیت تعداد تلاش ورود به پنل |
| ⏰ **Cron** | ریست دوره‌ای حجم، چرخش پراکسی خراب، بکاپ روزانه |
| 🤖 **ربات تلگرام** | وب‌هوک اختصاصی و ارسال بکاپ JSON به ادمین |
| ⚡ **کش D1** | کش کوتاه‌مدت پرس‌وجوها (حدود ۲.۵ ثانیه) |
| 📲 **PWA** | نصب روی گوشی با Service Worker و آیکن |
